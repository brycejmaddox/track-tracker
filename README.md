# Track Time Tracker

A command-line Python program for logging, analyzing, and managing race times. Built as a self-directed project while learning Python through the University of Helsinki's Programming MOOC.

## Features
- Add, remove, and replace race times
- Calculate fastest, slowest, and average time for an event
- Menu-driven interface that runs continuously until the user exits
- Case-insensitive input handling

## Concepts used
Lists, functions, loops, conditionals, `while` loops, string methods, and variable scope.

## How to run
python track_tracker.py
Follow the on-screen menu prompts to add times and view stats.

## Why I built this
I mainly created this program as a way to showcase what I've learned so far about Python, while also connecting my personal interest in track and field. Doing this not only provided me with a hands-on learning opportunity, but also allowed me to dive deeper into my exciting journey into the world of computer science.
